# Démarrage de l'interface

1. Cloner le dépôt de l'équipe, puis se placer dans le dossier du projet.
2. Lancer l'outil :

   ```
   python3 startCloud.py 
   ```

   Résultat attendu : Dans le terminal, un menu de selection vous permet de parametrer l'outil : 
```
[] - Selection de la memoire
[] - Configuration des ports
[] - Monitoring
```
